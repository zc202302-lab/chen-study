## 自动部署版本核验

镜像通过APP_REVISION记录构建提交，/version公开只读返回该提交，不包含配置或学习数据。自动更新检查运行容器的版本而非仅检查Git HEAD；即使代码合并后构建失败或被中断，后续定时器仍会重试通过CI的目标版本。update.sh传入构建版本，并在容器健康后核验实际运行版本。此修复消除代码层面的跳过风险，不能替代服务器日志确认某次故障根因。

Work需求页从当前课程配置读取期数、晋级分数、分项门槛和发布小时，根据实际课时显示创建、续接、后续教学或完成状态。已发布课时的题型分值来自题目快照。定时任务编号和无人值守证据单独记录，标明本站未独立核验，不把首期发布等同于自动化成功。

推送设置：config.schedule固定Asia/Shanghai，pushTime主推送、reviewTime复查补漏，mode为daily或progress。复查只补发应发未发的内容，不重复发布。进度模式以提交测验为前置条件。新设置不自动修改外部ChatGPT任务，Work须同步主推送和复查两次检查并验证；旧课程不自动迁移。

右侧提供独立保存按钮、未保存/已保存状态及离开提醒。新建课程尚无服务端课程编号，按钮保存到本浏览器localStorage草稿并明确提示，刷新可恢复；保存完整课程时正式入库。pending课程需求编辑通过事务接口仅保存courseRequirements，不覆盖其他设置。压缩多余空行及Markdown标题周边空行，保留段落分隔与代码围栏内容，减小标题、行距和内边距以增加可见内容。
